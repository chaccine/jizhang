# 日常账本

中文、移动优先的个人每日记账网站，纯 HTML / CSS / JavaScript，无构建步骤，无后端。

## 使用

直接打开 `index.html` 即可使用；也可以在当前目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000`。推荐通过 HTTP 使用，以获得稳定的浏览器存储行为。

- **界面**：奶油色移动优先布局，桌面居中显示（最大 480px）；自动跟随系统深色模式。底部“记账 / 明细 / 统计”使用 `#home / #bills / #stats` 切换。
- **记一笔**：点击悬浮 + 打开底部表单，支持 Esc、遮罩和关闭按钮退出。输入大于零、最多两位小数的金额，选择收入或支出、对应分类和日期，填写可选备注。日期默认为本地今天。
- **今日概览**：查看今天的收入、支出、结余及记录。
- **账单明细**：默认显示当月；日期和月份筛选互斥，点击“查看全部”取消筛选。支持搜索备注或分类、按日期分组和每日小计；首页和明细均支持编辑与确认删除，编辑在预填的底部表单中完成。
- **月度观察**：可选择月份，查看分类支出环形饼图、截至今天的近 7 天支出柱状图及分类金额、占比。图表使用真实账单数据绘制为原生内联 SVG，无外部依赖。近 7 天图表独立于月份筛选。
- **月预算**：按统计月份独立保存。使用超过 80% 显示警告，超出预算显示超支金额。输入 `0` 取消该月预算。

## CSV 备份与恢复

“导出 CSV”导出**全部账单**，不受筛选影响。文件带 UTF-8 BOM，可用 Excel 打开，正确处理备注中的逗号、双引号和换行。

导入格式（第一行为固定表头）：

```csv
日期,类型,分类,金额,备注
2026-10-25,支出,餐饮,28.50,午饭
2026-10-25,收入,工资,6000.00,十月工资
```

支出分类：餐饮、交通、购物、学习、娱乐、居住、医疗、其他。收入分类：工资、兼职、红包、其他。金额以元为单位，不使用千分位，最多两位小数；日期为有效的 `YYYY-MM-DD`；备注最多 200 字。

导入限制为 5 MB、UTF-8 编码。文件全部校验通过并确认后追加，不覆盖现有账单；任一行错误均取消整次导入。日期、类型、分类、金额和备注完全相同的记录视为重复并跳过（包括文件内重复）。备注可能引起 Excel 公式执行时，导出会加前置单引号，重新导入时还原。CSV 仅备份账单，不包含预算。

## 数据保存

账单和各月预算保存在当前浏览器、当前站点的 `localStorage`，键名为 `daily-ledger-v1`。金额以整数分保存。没有服务器同步，不会上传账单。不同浏览器、设备或域名不共享数据；清除站点数据会删除账本，请定期导出。隐私模式或浏览器禁用存储可能导致保存失败，页面会明确提示。无法读取已有数据时暂停写入，避免覆盖原数据。没有预置示例账单。

## GitHub Pages 部署

1. 将 `index.html`、`style.css`、`app.js` 和 `README.md` 提交到 GitHub 仓库根目录。
2. 打开仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择对应分支和 `/ (root)`，保存后访问 GitHub 显示的 Pages 地址。

本地资源均使用相对路径，支持仓库子路径。无外部资源或依赖。无需 npm、构建或密钥。

## 文件说明

- `index.html`：页面与表单、图表容器。
- `style.css`：响应式布局、配色与可访问性样式。
- `app.js`：账单、存储、预算、统计与 CSV 逻辑。
- `README.md`：中文使用及部署说明。
